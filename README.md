Traffic Light Control System

Description

A traffic light controller designed using Arduino Uno and simulated in Wokwi.

Components Used

- Arduino Uno
- 2 Red LEDs
- 2 Yellow LEDs
- 2 Green LEDs
- 6 Resistors

Pin Connections

Road A:

- Green → Pin 2
- Yellow → Pin 3
- Red → Pin 4

Road B:

- Green → Pin 5
- Yellow → Pin 6
- Red → Pin 7

Working

1. Road A Green + Road B Red
2. Road A Yellow + Road B Red
3. Road A Red + Road B Green
4. Road A Red + Road B Yellow
5. Repeat
